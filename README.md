# Personal Engineering & Web Portfolio

A responsive personal portfolio website built with HTML5, CSS3, JavaScript, and W3.CSS. It showcases technical engineering projects, CAD designs, programming experience, and web development archives.

---

## Overview

* **Owner:** Cigashamwa Eli Byamungu
* **Focus:** Engineering Physics at Morgan State University (Aerospace, Mechanical Design, CAD, and Python development)
* **Design Framework:** Responsive layout utilizing [W3.CSS](https://www.w3schools.com/w3css/) with custom CSS styling and parallax scrolling effects.

---

## Features

* **Responsive Navigation:** Dynamic navbar that toggles for mobile viewports and transitions styling on page scroll.
* **Parallax Visual Sections:** Full-width hero and section divider imagery configured with fixed background attachments.
* **Portfolio Archive:** Interactive links showcasing early web development work, sports media landing pages, and interactive projects.
* **Integrated Media:** Embedded audio playback support via SoundCloud iframe integration.
* **Contact Hub:** Direct communication touchpoints for engineering collaboration, project feedback, and inquiries.
